# Проект: Редизайн и мобильная адаптация SKUFenger

## Архитектура
Мессенджер SKUFenger построен на базе трехпанельного SPA-интерфейса:
- **Боковая панель (.chat-sidebar)**: Список чатов, настройки, выбор тем.
- **Главная область чата (.chat-main)**: Шапка чата, история сообщений, область ввода (#chat-input).
- **Вспомогательные панели**: Модальные окна настроек, оверлей авторизации.

Стили разделены по файлам:
- `frontend/style.css` — базовые стили, темы оформления (`[data-theme]`), медиа-запросы адаптации.
- `frontend/chat.css` — баблы сообщений, сетка чата, инпут.
- `frontend/style-modal.css` — оверлеи и модальные окна.

Клиентский JS-код:
- `frontend/messenger_app.js` — инициализация, логика вьюпорта (`visualViewport`), переключение экранов.
- `frontend/chat_core.js` — WebSocket-соединение, загрузка вложений, контекстные меню, выпадающие списки.

## Контракты интерфейсов

### Долгий тап / Правый клик для сообщений
- На десктопе: правый клик (событие `contextmenu`) вызывает кастомное меню `.msg-context-menu`.
- На мобильных (<= 768px): долгий тап (событие `touchstart` -> `touchend` с задержкой 500мс) вызывает `.msg-context-menu`.
- Стандартный левый клик (десктоп) / быстрый тап (мобильные): выделяет текст или осуществляет клик по ссылкам/вложениям.

### Жест Swipe-to-Back (.chat-main ↔ .chat-sidebar)
- Активируется только при ширине экрана <= 768px.
- Отслеживает события `touchstart`, `touchmove`, `touchend`.
- Сдвигает элемент `.chat-main` по оси X (`transform: translateX(Npx)`).
- Порог срабатывания: сдвиг на 120px вправо скрывает `.chat-main` (удаляет/добавляет класс `.chat-open`). Если сдвиг меньше 120px, чат плавно возвращается на исходную позицию.

## Код-макет (Code Layout)
- `frontend/index.html` — Разметка страницы авторизации и модальных окон настроек.
- `frontend/messenger.html` — Разметка основного интерфейса мессенджера.
- `frontend/style.css` — Стили тем оформления (`[data-theme]`), медиа-запросы, общие стили.
- `frontend/chat.css` — Стили разметки чата, полей ввода.
- `frontend/messenger_app.js` — Логика вьюпорта и переключения представлений.
- `frontend/chat_core.js` — Обработка сообщений, контекстных меню и вложений.
- `tests/e2e/` — Директория со спеками E2E-тестов Playwright.
